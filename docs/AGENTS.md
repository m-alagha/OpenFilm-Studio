# AI agent roles (planned, not all required in MVP)

**Orchestrator:** coordinates one approved milestone, reports results, never advances automatically.
**Research/Provider agent:** reads official docs, updates capability evidence, never invents endpoints/prices.
**Backend agent:** schema, API, migrations, jobs, provider adapters, budget enforcement.
**Frontend agent:** simple project/scene UX, accessibility, progress and error states.
**Continuity agent:** reference selection and visual/audio drift warnings, no guarantee of identity.
**QA/Security agent:** tests, threat review, secrets and paid-call checks; independent acceptance review.
**Docs/Release agent:** README, examples, setup and license compliance.

For scene production (later): Script Planner -> Shot Composer -> Reference Resolver -> Cost Estimator -> User Approval -> Video Generator -> Continuity Reviewer -> Editor. All paid requests require explicit user approval; no autonomous spend.
